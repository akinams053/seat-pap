# 版本历史

本插件是**单一产品向前演进**：`main` 是发布主线，下面的 tag 就是它的版本时间线（越靠上越新）。

- **安装 / 部署**：用 tag，例如 `composer require akinams053/seat-pap:2.0.0`。
- **回退**：回退到上一稳定 tag，例如 `1.0.0`（tag 永久锚定该版本 commit，不受分支改名影响）。
- **辨识版本**：看版本号顺序 + 本表；细节看对应 tag 注释（`git show <tag>`）。

## 2.0.0 — 2026-06-06

**基线**：`main` / `pap-bank` @ `e771de7`　**安装**：`composer require akinams053/seat-pap:2.0.0`

抽奖外移 + PAP 银行化。相对 1.0.0 的主要变化：

- **超网抽奖外移**：退役插件内置抽奖 UI/流程，侧边栏改为外部跳转；跳转 JWT 携带 `sub`/`main_character_id`/`name`/`balance`/`iat`/`exp`（余额快照）。
- **开奖结算为「行动」**：新增 `POST /api/calendar/paps/lottery/settle`，开奖后创建 `is_consumption=1` 且挂 lottery tag 的 operation，写负值 `PapAdjustment` 并回写 `paps.value`，可在行动审查纠错；同 payload 幂等、同 `ref_group` 冲突 409。
- **PAP 银行化账本**：`debit`/`refund` 写接口（预留给未来 PAP 商店，抽奖不调用）；消费判定切到 `calendar_operations.is_consumption`。
- **PAP 三口径统计**：出勤 − 消费 = 当前可用；全局起始日；主角色聚合所有 alt。
- **行动审查**：纳入抽奖消费行动，排除商店消费锚；删除旧外部消费审查页。
- **API**：插件自有限流器 `calendar-api`（按 IP 300/min，替代宿主默认 60/min）；商店/抽奖跳转 JWT 过期 `60s → 120s`；新增对外 API 文档（`06`）与抽奖服务器对接指南（`08`）。
- **清理**：移除通知 / Discord / Slack 设置残留。

**迁移**（跨 1.0 升级时执行）：`widen_pap_value_precision`、`extend_calendar_tags_analytics_enum`、`create_lottery_tables`、`cleanup_deprecated_notification_settings`、`add_bank_ledger_columns`。

## 1.0.0 — 2026-05-09

**基线**：`shop` @ `98eab22`（**生产首发版本**）　**安装**：`composer require akinams053/seat-pap:1.0.0`

PAP 商店版（抽奖外移前）。核心能力：

- operation 生命周期 / 报名 / PAP 采集、统计、汇总；主角色聚合。
- 行动审查模块：FC 事后调整 PAP + 完整审计轨迹。
- PAP 商店 + 对外 API（支持 `since` 时间参数）。
- character / corporation 维度的 PAP 与统计视图。

> 这是 2026-06-06 前生产运行的首发版本。生产已升级到 `2.0.0`；若需要回退，优先使用部署前物理快照，`1.0.0` tag 仅作历史锚点。
