## 4. 接手人必须知道的当前行为

- **开奖按钮何时出现**：售满（`sold_out`）显示「开奖」；`open` 且 ≥1 个已售节点时对 FC / 管理员显示「提前开奖」；一个都没卖出时不显示。
- **提前开奖语义**：`status=open` 且 `sold_count>0` 触发，只从已售节点抽，未售节点写 `voided_at` 作废，`draw_mode=early`。
- **整行动清零语义**：对当前 action 下每个 `paps.value != 0` 成员追加反向 `PapAdjustment` 冲正为 0，不删历史；已是 0 的跳过；未终态 lottery action（`open`/`sold_out`）会被后端拒绝。
- **抽奖消费即时进统计**：负数 `paps.value` 会即时进入角色 / 军团 PAP 统计，使统计混合出勤 / 消费 / 可用——这是阶段 7 要处理的已知现象，非缺陷。

```bash
cd /var/www/seat
sudo composer update akinams053/seat-pap --no-cache
sudo -u www-data php artisan view:clear
```
