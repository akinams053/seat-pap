# 舰队指挥 PAP 操作指南

本文档面向舰队指挥（FC），介绍从创建行动到 PAP 发放的完整流程。

---

## 前提条件

在使用 PAP 功能之前，请确认以下事项：

1. **你的角色已在 SeAT 中注册并授权**，且具有以下 ESI 权限：
   - `esi-fleets.read_fleet.v1` — 读取舰队成员列表
   - `esi-fleets.write_fleet.v1` — PAP 发放后自动更新舰队 MOTD

2. **你的 SeAT 账号拥有 `calendar.create` 权限**（由管理员分配）

3. PAP 发放时，**你必须是舰队的 fleet boss**

> 如果你不确定是否已授权 `write_fleet` 权限，请联系管理员。缺少该权限不影响 PAP 发放，仅影响 MOTD 自动更新。

---

## 第一步：创建行动

1. 打开 SeAT，在左侧导航栏找到 **日历 → 行动**
2. 点击右上角 **创建新行动** 按钮，弹出创建表单

### 表单字段说明

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| **标题** | 必填 | 行动名称，同时也是 MOTD 中显示的舰队名 |
| **角色限制** | 选填 | 限制哪些 SeAT 角色可以看到和报名此行动 |
| **重要性** | 必填 | 0-5 滑块，用于排序和标识优先级 |
| **标签** | 选填（建议填写） | 勾选一个或多个标签。标签的 **解析轴** 决定 PAP 类型（如 Strategic、PvP），**量化** 值决定本次 PAP 数量 |
| **持续时间** | 必填 | 选择"是"可设定起止时间，选择"否"则只设开始时间 |
| **时间** | 必填 | 根据上一项选择，填写开始时间或起止时间范围 |
| **集结星系** | 选填 | 输入星系名会自动补全 |
| **集结信息** | 选填 | 空间站、堡垒等集结地点的补充说明 |
| **舰队指挥** | 必填 | 输入你的角色名，会自动匹配 SeAT 中已注册的角色 |
| **描述** | 选填 | 行动的详细说明，支持 BBCode 格式 |

### 关于标签

标签有两个关键属性影响 PAP：

- **量化（Quantifier）**：决定本次行动发放多少 PAP。如果勾选了多个标签，取最大值
- **解析轴（Analytics）**：PAP 类型名称（如 Strategic、PvP、Mining），会显示在统计图表和 MOTD 中

**建议：至少勾选一个带有量化值的标签，否则 PAP 值默认为 0。**

3. 填写完成后，点击 **创建这个行动**

---

## 第二步：等待行动开始

- 行动创建后，状态为 **即将到来**，成员可以在此期间报名
- 当行动时间到达后，自动进入 **进行中** 状态
- PAP 发放按钮仅在行动状态为"进行中"或"已停止"时显示

---

## 第三步：发放 PAP

当行动进行中，你在行动列表的舰队指挥一栏会看到一个 **PAP 发放** 按钮。

### 首次发放

1. 确保你在游戏中已组建舰队，并且是 **fleet boss**
2. 确认舰队成员齐全后，点击 **PAP 发放** 按钮
3. 系统弹窗提示：

   > 舰队共有 **X** 名成员。请确认舰队成员完整后再发放 PAP。
   >
   > 这是本次行动的首次 PAP 发放，所有当前舰队成员都将获得 PAP。

4. 确认无误后，点击 **确认发放**
5. 系统为舰队中的所有成员创建 PAP 记录，并自动更新舰队 MOTD

### 补发（再次点击发放按钮）

如果有新成员在首次发放后加入了舰队，你可以再次点击 **PAP 发放**：

1. 系统自动对比当前舰队成员与已发放记录
2. 弹窗显示差异：

   > 舰队共有 **X** 名成员，其中 **Y** 人已发放。将为 **Z** 名新成员补发 PAP。
   >
   > **以下成员将补发 PAP：**
   > - 角色名 A
   > - 角色名 B

3. 确认后，仅为新加入的成员补发 PAP，已发放过的成员不会重复

### 全员已发放

如果当前舰队成员全部已经发过 PAP，弹窗会提示：

> 所有舰队成员均已发放本次行动的 PAP，无需补发。

此时不会显示确认按钮。

---

## 发放后的效果

### 舰队 MOTD 自动更新

PAP 发放成功后，舰队 MOTD 会自动更新为彩色通知，内容包括：

- 舰队名称（行动标题）
- 舰队人数
- 本次 PAP 数量
- PAP 类型
- 发放时间
- 底部签名

如果发放过程出现错误，MOTD 会显示红色错误提示。

> MOTD 更新失败不影响 PAP 的正常发放。

### PAP 统计

发放的 PAP 会自动计入统计：

- 成员可以在 **角色侧栏 → Paps** 查看个人 PAP
- 军团管理可以在 **军团侧栏 → Paps** 查看军团统计和排名
- 所有 PAP 数据会按**主角色聚合**（alt 产生的 PAP 归并到主角色名下）

## 常见问题

### PAP 发放按钮不见了？

- 确认行动状态是"进行中"或"已停止"
- 确认行动的舰队指挥设置的是你当前登录的角色

### 点击发放后提示 "Character is not in a fleet"？

- 你的角色当前不在舰队中，请先在游戏里组建或加入舰队

### 提示 "The fleet does not exist or you don't have access to it"？

- 你不是 fleet boss。请确保你在游戏中是舰队的 boss（不是 wing/squad commander）

### 提示 token 权限不足？

- 你的角色 ESI 授权缺少 fleet 相关权限，需要在 SeAT 中重新授权角色
- 需要先到 [EVE 第三方应用管理](https://community.eveonline.com/support/third-party-applications/) 撤销旧授权，再重新授权

### 发错了 PAP 怎么办？

- **小幅调整**（个别成员奖励或扣除）：使用 [行动审查](#行动审查与-pap-奖惩调整) 功能即可
- **整批撤回**：删除行动会同时清空该行动下的所有 PAP 记录与审查记录
- 如需保留行动但完全撤回 PAP，请联系管理员

### 多次点击发放会重复吗？

- 不会。已发放过 PAP 的成员不会重复发放，只会为新成员补发

## 行动审查与 PAP 奖惩调整

发放 PAP 后，FC 可对个别成员做**事后奖励或扣除**——比如某成员中途离队、某成员表现突出、某成员临时替补。调整结果会实时反映到所有统计页面和外部商店 API。

### 入口

侧边栏 **日历 → 行动审查**，列出所有已发放 PAP 的行动。

### 列表显示

| 列 | 说明 |
|---|---|
| 行动标题 | 行动名称 |
| PAP 发放时间 | 最近一次该行动 PAP 发放的瞬间（精确到秒，UTC） |
| 舰队指挥 | FC 头像与名称 |
| 单 PAP | 行动 tag 量化值，每位成员获得的基础 PAP |
| 人数 | 已发放 PAP 的成员总数 |
| 总额 | 所有成员当前 PAP 之和（含奖惩） |
| 操作 | **PAP 审查** 按钮 — 仅对 FC 本人显示，其他用户显示「非 FC」 |

### 审查弹窗

点击 **PAP 审查**，弹出该行动的成员明细：

- 每行显示成员、船型、星系、加入时间、当前 PAP 值、奖惩历史
- 旧行动（本功能上线前发放的）船型可能正常显示，但**星系列**和**加入时间**会显示「—」
- FC 本人的视图末尾多一列「操作」：
  - **绿色 +** 按钮 — 奖励
  - **红色 −** 按钮 — 扣除

### 奖励 / 扣除流程

1. 点击 **+** 或 **−** 按钮，弹出录入窗口
2. 填写：
   - **数量**：正数（方向由按钮决定）
   - **类型**：自动继承自本次行动的 tag 解析轴，无需选择
   - **奖惩理由**：必填，最多 255 字
3. 点击 **确认奖励** / **确认扣除**
4. 弹窗关闭后，成员行的 PAP 列**实时更新**，奖惩历史列追加一条记录

### 调整规则

- **同一成员可被多次调整**，每次产生一条独立的审计记录（金额、理由、操作人、时间）
- **调整结果实时回写** `paps.value` 字段，所有统计页面、军团排名、外部商店 API 自动同步
- **可以扣到负数**（FC 自行决定纪律记账）；商店端 API 会用 `max(0, total)` 兜底，避免负余额
- **删除行动**会同时清空该行动的 PAP 与所有审查记录

### 权限

| 行为 | 权限要求 |
|---|---|
| 查看行动审查列表 | `calendar.view` —— 所有日历用户均可 |
| 查看成员明细弹窗 | `calendar.view` + 行动可见性 —— 只读 |
| 点击奖励/扣除按钮 | **必须是该行动的 FC 本人**（与 PAP 发放的权限完全一致） |

后端会强制校验，即使有人手动绕过前端，非 FC 提交也会被拒。
